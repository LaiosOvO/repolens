# 稿件风格配方（STYLE 三种）

以下配方提炼自对四位高质量技术教学博主 370 期视频转录稿的分析。写稿时必须严格执行所选配方的结构、口头禅与收尾动作。

## 一、tutorial：教程式（默认，5–7 分钟中长稿）

适用：教观众用一个工具/项目。六段式骨架：

### 第 0 节 · 定场（约 100 字）
- 交代系列名与集数："今天咱们来聊一个事儿，{工具}的{主题}。这是第 N 集，上一集咱们聊了{上集主题}。"
- 单集稿可省略集数，但必须有一句定场。

### 第 1 节 · 痛点钩（约 150 字）
- 用"有朋友跟我说……"或"你有没有遇到过这种情况……"引出一个具体、有画面感的痛点（带细节：三个 bug、改 50 个文件、提交后 CI 报错）。
- 收束句式："那么问题就来了，{观众心里的疑问}？还真有，就是今天咱们要说的{主题}。"

### 第 2 节 · 概念解释（约 250 字）
- "说到这儿可能有朋友要问了，{主题}是啥？我打个比方你就明白了。"
- 主比喻取自日常生活（机场安检、盖房子、导航、USB 接口、实习生入职），先把生活场景讲完整，再落" {主题}就是这个原理"，最后一句技术定义收口："简单说，XX 就是让 AI……"

### 第 3 节 · 主体清单（约 800–1000 字，全文主体）
- 引导句："我总结了 N 个最实用的场景，咱们一个一个说。"N=3 为宜。
- 每个场景三段式：①痛点（"你肯定遇到过……"）②具体做法（命令/配置/步骤，具体到能照抄，必须来自 evidence）③数字佐证（"失败率降低 80%""效率提升六倍"）。
- 每个场景讲完用"说到这儿，这就很关键了，……"拔高一句价值。

### 第 4 节 · 实战演示（约 400 字）
- "说了这么多，咱们来做一个实战演示。"
- 口述式推演："假设你要做 X，你只需要说一句话……然后你看它会怎么做：第一步……第二步……"，分 3–4 步，每步一句结果描述。演示案例用仓库最普适的功能。

### 第 5 节 · 避坑/进阶（约 400 字）
- 钩子："可能有朋友要问了，这玩意儿这么好用，有没有啥坑啊？还真有。"
- 列 3 个坑，每个必须带"解决办法是……"；或列 3–4 条"最佳实践一定要记住，第一……"。坑的内容优先取仓库 issues/文档中的真实陷阱。

### 第 6 节 · 收尾（约 200 字）
- "好了，今天咱们就聊到这儿，回顾一下重点。第一……第二……第三……"（与第 3 节三点一一对应）
- 下集预告 + 承上启下对比句："如果说{本集主题}是{比喻}，那么{下集主题}就是{比喻}。下集咱们详细说。"
- 固定 CTA："别忘了点赞、收藏，关注系列持续更新，咱们下期再见。"

### 短视频变体（LENGTH=short，约 800 字 / 1.5 分钟）
压缩为：痛点开场 → 一个比喻 → 用法 → "记住一句话就够了"式口诀 → 下集预告。砍掉避坑段，演示压成一句命令。

## 二、teardown：拆解式（4–9 分钟）

适用：讲透一个开源项目的架构与工程判断。骨架为"问题 → 误判 → 本质 → 拆解 → 落地建议"：

1. **开场钩**：反直觉断言或场景痛点（"Agent 最可怕的不是没记性，而是他记错了还一直信"级别）。
2. **立误判**："很多人把 X 理解成……这都太浅了。"
3. **给框架**：自己的判断框架（"X 的主链路其实就三件事"），框架必须来自 evidence 中的真实结构。
4. **同一案例贯穿**：全程用一个具体场景（修登录 bug、等 CI）把框架走完。
5. **落地建议**："我自己的判断是……"——具体文件分层、操作顺序、先做什么后做什么。
6. **收尾**：一句金句（机制层面的对仗句）+ 评论区互动问题 + 签名式自我介绍。

语言气质：评论员的松弛 + 工程师的较真；敢下立场、敢点名对比；比喻密集且有画面感。

## 三、interview：面试题式（1–3 分钟）

适用：把仓库知识点转成面试问答弹药。七段式模板：

1. **还原题目 + 错误答案预警**（0–15s）："面试官问 XXX？你如果只回答 YYY，这个回答一定不够。"错误答案必须是观众最可能脱口而出的直觉答案。
2. **定性纠偏**：一句话指出题目真正考察的层面（"表面在问 token，实际在考上下文选择"）。
3. **先给结论**：一句话给出答案主干。
4. **分类拆解**（占 50–60%）：切成 3–4 类，每类"定义 + 具体例子 + 不管它会出什么事故"，例子必须取自当前仓库的真实机制。
5. **标准答案口播**："面试里可以这样回答，我……"——30–50 字第一人称、可直接背诵。
6. **收尾三选一**：口诀总结 / 升维一句 / 互动思考题 + "我们下期见"。

## 通用语言规范（三种风格共用）

- 通篇"咱们"视角（interview 式可用"你"），自问自答推进，句长控制在口语一口气能说完的长度；
- 英文术语直接嵌中文句子，首次出现配一句中文注解；命令用中文读法（"斜杠 batch""点 md"）；
- 数字是最强说服工具，每个论点尽量带可感知的数字或算账；数字必须来自 evidence，没有就不用；
- 口诀化金句用于记忆点收口（"把记的做变成自动做"式对仗）；
- 禁止词："本文""如下图所示""综上所述""赋能""抓手"等书面/黑话语汇。
