# 发布物料合同（publish-kit）

配套稿件产出后，为每一集视频生成可直接投稿的发布物料，写入 `script/publish.md`。所有内容（数字、命令、承诺）必须与稿件和证据基座一致，禁止为了流量夸大或引入未经验证的说法；稿件里没有的事实一条都不许出现。

## 文件结构（六个板块，顺序固定）

### 1. 标题（三版任选）

- **A · 痛点利益版**：`{痛点现象}——{解法承诺}`，从稿件痛点钩取材；
- **B · 反直觉版**：颠覆直觉的断言，从稿件概念解释的主比喻取材；
- **C · 数字清单版**：`{N} 个 {对象} + 利益点`，N 取稿件里的真实数字（场景数、坑数、链路段数）。

规范：每版 ≤30 字；前 12 字必须含最强钩子；至少一版含数字、一版含仓库/工具名（利于搜索）；不堆感叹号。

### 2. 封面文案

- **主标**：≤12 字，用本集最强反差词（稿件主比喻的核心名词优先：塔台、搬家公司、不关机、进错门）；
- **副标**：≤16 字，补利益点或数字；
- **角标**：`{系列名} · 第 N 集`（单集稿写 `源码拆解` / `上手教程`）。

### 3. 简介（固定五段）

1. **钩子句**：直接复用稿件痛点钩的收束句（可微调字数）；
2. **本集看点**：3 条，与稿件主体清单三场景一一对应，每条 ≤20 字；
3. **证据背书**：一句话声明源码级拆解 + commit 快照 + 行号可查；
4. **系列导航**：系列稿注明总集数与本集位置；单集稿注明后续更新方向；
5. **CTA**：收藏 + 关注，与稿件收尾 CTA 同调。

规范：全部口语短句；禁书面语（禁词表同 style-recipes.md）；简介可整体粘贴进发布框。

### 4. 标签（三层，共 6–9 个）

- **流量层**（2–3 个）：大盘词，如 `#AI编程` `#Agent` `#程序员` `#开源项目`；
- **主题层**（2–3 个）：品类词，如 `#CodingAgent` `#ClaudeCode` `#多Agent`；
- **精准层**（2–3 个）：本集专名——仓库名、核心机制名（如 `#LoopX` `#AgentLoop` `#沙箱`）。

### 5. 分段时间轴

- 按稿件节次切分；起点 = 该节前累计字数 ÷ 总字数 × 总时长；
- 时长口径：400–430 字/分钟（与进度手册一致），取区间中点标注；
- 每段一行：`{时间点} | {章节名} | {一句话内容点}`；
- 主体清单内的子场景单独列行（观众跳看的主要落点）；
- 总时长与稿件字数预估值一致（±0.2 分钟），系列稿与系列大纲口径一致。

### 6. 置顶评论文案

- 仓库地址 + 分析基于的 commit 快照；
- 行号时效声明："行号以该快照为准，上游更新后以代码为准"；
- 配套产物说明（报告/提词器的获取方式，是否公开按用户指示）；
- 互动问题：从痛点钩或收尾改造，一个观众可在评论区直接作答的具体问题。

## 质量门

- 三版标题至少一版含数字、至少一版含仓库名或品类词；
- 简介三条看点与稿件三场景一一对应，无第四条；
- 时间轴每段内容点能对应到稿件对应节的原文；
- 物料与稿件、报告三方数字不打架（命令、路径、行号、百分比）。
