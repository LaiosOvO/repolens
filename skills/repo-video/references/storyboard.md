# 分镜交接稿合同（storyboard.md）

分镜交接稿是口播稿件（manuscript.md）与视频渲染（Remotion / HyperFrames）之间的唯一交接物：把稿件拆成可渲染的场景数组，让下游只管排版、配音和渲染，不再回头读稿件做理解。

## 输出

`script/storyboard.md`（系列稿每集一份 `script/ep{N}-storyboard.md`）。

## 必填结构

1. **片头信息表**：标题、目标画幅（1080×1920 竖屏 / 1920×1080 横屏）、fps（默认 30）、总场景数、预估总时长、首帧即封面声明。
2. **场景表**（每场景一行或一小节，字段缺一不可）：

| 字段 | 内容 |
|---|---|
| `scene_id` | s01… 顺序编号 |
| 口播原文 | 该场景配音的逐字稿（从 manuscript 原样切分，不改写） |
| 画面类型 | 从场景类型词表选（见下） |
| 强调元素 | 说到哪个关键词/数字/命令时画面同步强调什么（字词级同步锚点） |
| 素材 | 引用路径：真实运行截图、录屏、代码片段、图表数据；无素材写「纯排版」 |
| 预估秒数 | 按 400–430 字/分钟口播语速估算（TTS 约 1.35x 时按 550 字/分钟） |
| 转场 | 与下一场景的衔接（淡入/切/推镜），默认硬切 |

3. **字幕安全区与封面检查清单**：底部内容 padding ≥ 290px（竖屏）；封面场景静态无入场动效；全片单一强调色。

## 场景类型词表（对齐下游组件）

`cover`（静态封面）/ `title-card`（反白重音页，全片 2–3 处）/ `key-points`（左 label 右值列表）/ `big-number`（大数字滚动）/ `steps`（01→02 流程轴）/ `comparison`（左右对比 + 结论条）/ `demo-terminal`（终端实录/截图 + 逐行高亮）/ `code-walk`（代码片段 + 行号高亮）/ `diagram`（架构图/流程图）/ `pitfall`（坑：问题 + 解法两栏）/ `closing`（CTA 收尾页）。

## 规则

- 每场景口播 2–3 句（5–10 秒配音）；全片 15–25 个场景；单场景超 12 秒必须再拆。
- 所有命令、配置、路径、数字必须与共享证据基座一致；分镜不得引入稿件之外的新事实。
- 演示场景（demo-terminal / code-walk）优先引用**真实运行截图/录屏**；没有实拍素材的场景必须在素材列写「待补拍：xxx」。
- 下游对接：Remotion 路线把场景表机械翻译成 `config.ts` 的 SCENES 数组；HyperFrames 路线把每个场景写成一个 HTML section + GSAP 时间轴。交接稿本身不含任何框架代码。
